## Aperture Science Handheld Portal Device (ASHPD / "portal gun")

- Fires two linked portals, blue and orange. Only one of each colour exists at a time; firing a new blue portal moves the existing blue one. _source: deep-research handoff 2026-06-02 · capture: web_fetch · confidence: high · enemy-tier: 0 · puzzle-tier: 0 · category: mainline · spoiler: none_
- **Acquisition (two stages):** the **blue-only** device is retrieved from a pit in **Chamber 02** (via automated portals); the fully powered **dual-portal** device is acquired in **Chamber 11** -- picking up the orange portion triggers the "Lab Rat" achievement. Chambers 00-01 have no player-held gun. _source: deep-research handoff 2026-06-02 · capture: web_fetch · confidence: high · enemy-tier: 0 · puzzle-tier: 0 · category: mainline · spoiler: progression · ach: lab_rat · achievement-hidden: no · trigger_type: progression_
  > see achievements.md for the Lab Rat entry.
- **Surface compatibility:** attaches only to flat, light-coloured/concrete-type surfaces; dark metallic brown/black panels, glass, and moving surfaces reject portals (see `mechanics.md`). _source: deep-research handoff 2026-06-02 · capture: web_fetch · confidence: high · enemy-tier: 0 · puzzle-tier: 0 · category: mainline · spoiler: none_
- **Grill pass-through:** the device passes freely through Material Emancipation Grills, but doing so resets (removes) both active portals and shakes the gun. _source: deep-research handoff 2026-06-02 · capture: web_fetch · confidence: high · enemy-tier: 0 · puzzle-tier: 0 · category: mainline · spoiler: none_
